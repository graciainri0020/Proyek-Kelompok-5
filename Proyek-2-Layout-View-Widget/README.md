# Proyek 2 - Layout View dan Widget

## Deskripsi
Proyek pembelajaran Android Studio tentang penggunaan Layout, View, dan Widget untuk membuat antarmuka aplikasi Android.

## Tujuan
- Memahami tata letak antarmuka aplikasi.
- Mengenal komponen View dan Widget.
- Mempelajari penggunaan Button, TextView, dan EditText.

## Tools
Android Studio
